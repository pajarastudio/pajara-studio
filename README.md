# Pajara Studio

Berakar di Tanah Pasundan.

Pajara Studio adalah studio desain grafis yang menyediakan layanan branding, desain promosi, dan kebutuhan visual untuk bisnis.

## Struktur Project

- `apps/website` — Website publik Pajara Studio
- `apps/customer-web` — Customer Web
- `apps/admin-app` — Pajara Admin App
- `packages/supabase` — Koneksi Supabase
- `packages/types` — TypeScript types
- `packages/ui` — Komponen UI bersama
- `packages/config` — Konfigurasi bersama

## Teknologi

- Next.js
- TypeScript
- React
- React Native
- Expo
- Supabase
